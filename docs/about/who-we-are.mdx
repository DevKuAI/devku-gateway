## Maintainers

Gateway is maintained by [DevKuAI](https://github.com/DevKuAI) in the
[devku-gateway repository](https://github.com/DevKuAI/devku-gateway).

## Upstream

This repository synchronizes code from the
[official upstream repository](https://github.com/ENTERPILOT/GoModel). Local
branding and distribution changes remain here, while upstream logic is
integrated as it evolves.
